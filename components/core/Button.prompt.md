# Button
The primary brand action; `variant="primary"` is Northeastern red, `arrow` appends the signature ↗.

```jsx
<Button variant="primary" arrow>Read the story</Button>
<Button variant="secondary">Subscribe</Button>
<Button variant="link" arrow>More research news</Button>
```

Variants: primary · secondary (black outline) · inverse (for dark bg) · ghost · link. Sizes: sm · md · lg.
