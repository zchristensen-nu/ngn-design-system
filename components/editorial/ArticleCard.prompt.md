# ArticleCard
Workhorse story card. `layout="stacked"` (feed/grid) or `"horizontal"` (list rows). Composes Tag + Byline.

```jsx
<ArticleCard image="/photo.jpg" category="Research"
  title="Northeastern scientists map the deep sea"
  dek="A new expedition returns with troves of data."
  author="Ian Thomsen" date="March 12, 2026" readTime="6 min read" />
```
